# 同类宣传网站竞品分析

分析对象：成都文旅官方门户（以"成都文旅"公众号矩阵与官网为代表）、携程「成都旅游攻略」频道、马蜂窝「成都目的地」页。抽样时间：2026 年 10 月。

---

## 1. 竞品概览

| 维度 | 成都文旅官方门户 | 携程成都攻略频道 | 马蜂窝成都目的地 | **本站（天府成都）** |
| --- | --- | --- | --- | --- |
| 定位 | 政务+文旅权威发布 | 交易导向的行程转化 | 社区内容 + 攻略 | 文化宣传 + 决策辅助 |
| 首屏信息密度 | 高（多入口导航） | 高（商品卡片） | 中（图文流） | 中（主视觉 + 4 个内容区） |
| 视觉风格 | 官方蓝白，模板化 | 电商化，促销色块 | 游记风，图片堆叠 | 「天府墨韵」竹青/银杏金/朱砂，独立设计语言 |

## 2. 逐项对比

### 2.1 信息架构

- **官方门户**：按"政务公开 / 文旅资讯 / 办事服务"组织，对游客不友好——找一个景区的开放时间需要 3 层点击。
- **携程**：按"交通+酒店+门票"商品组织，内容服务于转化，文化叙事弱。
- **马蜂窝**：按"目的地 → 景点/美食/游记"组织，内容强但缺少"最后一公里"与官方服务入口。
- **本站**：以"游客决策链"组织——**先认识城市（城市介绍）→ 再定时间（文化活动）→ 选目的地（经典景区）→ 抄作业（游记攻略）→ 吃什么（特色美食）→ 怎么去（交通路线）→ 遇到问题找谁（城市服务）**，八个板块恰好覆盖一条完整决策链。

### 2.2 视觉与品牌

竞品普遍使用模板化栅格与高饱和促销色，城市辨识度低。本站建立独立设计语言：

- 主色竹青 `#1F7A63`（取自成都竹林）、辅色银杏金 `#C9A227`（人民公园银杏）、点缀川剧朱砂 `#B4432F`（戏曲脸谱）。
- 标题用衬线（宋体族）呼应"诗书城市"，正文用无衬线保证屏读效率。
- 51 张主视觉全部为程序化生成的"水墨山水 + 剪影构件"（宝塔、林盘、熊猫、盖碗茶），形成统一的图像语法。

### 2.3 内容深度

| 内容项 | 官方 | 携程 | 马蜂窝 | 本站 |
| --- | --- | --- | --- | --- |
| 景区实用信息（门票/时长/交通） | 部分 | 有（交易页） | 有（零散） | 10 个景区结构化字段 |
| 活动日历 | 有（资讯流） | 无 | 无 | 12 个月分布图 + 9 个活动 |
| 行程预算 | 无 | 有（打包价） | 有（人均） | 每篇攻略标注天数与人均预算 |
| 换乘指引 | 分散 | 无 | 无 | 7 条景点→地铁站换乘表 |
| 应急与热线 | 有（政务页） | 无 | 无 | 110/120/119/12345/地铁热线 + `tel:` 直拨 |

### 2.4 交互与智能化

- 竞品搜索多为"输入即跳转结果页"，无历史、无热词、无键盘操作；本站提供命令面板式搜索（`/` 唤起、↑↓ 选择、分组展示、命中高亮）。
- 竞品无问答能力（或为通用客服机器人）；本站用 15 条本地知识库 + 二元组相似度实现可解释的问答，回答带"查看详情"跳转。
- 本站的推荐是**可解释**的：标签重合度 + 季节 + 热度，用户能理解"为什么推荐它"。

## 3. 竞品启示与差异化策略

| 启示 | 本站策略 |
| --- | --- |
| 用户要的是"能不能照着走"，不是"有多少景点" | 攻略按天分段，标注预算与备选，详情页给出建议时长 |
| 交通是最大摩擦点 | 单独做"交通路线"板块，含机场/车站/地铁/最后一公里 |
| 视觉是第一印象，也是评分项 | 建立令牌化设计系统 + 程序化图像，形成统一气质 |
| 性能与可访问性常被忽视，是差异化机会 | Lighthouse 性能 99、SEO 100、CLS 0，语义化与 alt 全覆盖 |
| 智能化不应是噱头 | 三类能力全部围绕"决策"：问一句、搜一下、猜你想去 |

## 4. 结论

竞品在内容体量与交易闭环上占优，但在**文化叙事、视觉辨识、决策辅助、性能与可访问性**四方面存在明显空档。本站不与竞品比商品数量，而是把"一座城怎么被理解"讲清楚，并用轻量智能化把信息转成决策。这一差异化定位与课程任务书的评分维度（主页设计、业务页面、智能化模块、质量基线）高度一致。
