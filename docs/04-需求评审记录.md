## 4. 范围确认

- **纳入**：8 个板块、4 类详情页、搜索页、404、智能化三件套、深浅主题、高对比、收藏、SEO、测试与审计。
- **排除**：用户注册登录、在线支付、真实预约下单、后台管理系统、多语言。
- **变更控制**：新增需求须在例会提出，评估对进度影响后由组长确认，并更新 PRD 版本号。
