设计稿迭代记录（三次推翻）：

1. **屋顶**：初版用三次贝塞尔画坡顶，渲染成"圆顶山丘"；改用梯形折线 + 反宇檐口后才读得出川西民居。
2. **熊猫**：初版为纯色墨团；改为双色（白身黑耳眼圈四肢）后辨识度达标。
3. **美食**：初版沿用山水构图，碗悬浮山间；改为独立静物构图（圆餐盘 + 碗 + 蒸汽 + 斜搁筷子 + 散落辣椒）。

## 4. 视觉资源生成方案

scripts/generate-art.mjs 用 Node 生成 46 张 SVG，规则：

- **构图**：16:9（HD，6 张）与 4:3（卡片，40 张）两套画布。
- **图层**：天空渐变（0.25 斜向）→ 日/月 + 径向光晕 → 3 团高斯模糊云 → 2-4 层山脊（Catmull-Rom 平滑，逐层加深）→ 层间雾化渐变 → 水面 + 倒影横线 → 主体剪影 → 地面曲线 → 暗角 → 白色内框 → 朱砂印章。
- **构件库**：古塔（5 层飞檐）、川西民居、桥、竹丛、松树、熊猫、天际线、乌篷船、灯笼、道路透视。
- **调色板**：7 套（晨晓 dawn / 黄昏 dusk / 青绿 jade / 夜色 night / 秋色 autumn / 雪景 snow / 雾色 mist）。
- **体积**：单张 3-12 KB，全部内置进 bundle，无外链请求。
- **性能**：初版含 feTurbulence 噪点滤镜，Lighthouse 性能仅 69；移除后首页 87、列表页 99（噪点使整幅 SVG 每帧重新栅格化）。

## 5. 动效规范

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 页面切换 | 300ms | ease-out | 淡入 + 上移 10px，mode="out-in" |
| 卡片悬浮 | 220ms | ease-out | 上移 4px + 阴影加深 + 描边变品牌色 |
| 滚动揭示 | 700ms | ease-out | 透明度 0→1、位移 22px→0，IntersectionObserver |
| 数字滚动 | 1400ms | easeOutCubic | 进入视口触发一次 |
| 轮播 | 6500ms | 线性 | 悬停/聚焦/切后台暂停 |
| 图片放大 | 600ms | ease-out | 悬浮 scale(1.045) |

所有动效在 prefers-reduced-motion: reduce 下自动关闭（时长降为 1ms 或直接置位）。
