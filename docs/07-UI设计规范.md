### 1.3 三层变量结构

```text
调色板（--c-*，固定值，不随主题变）
    ↓
语义 token（--bg-* / --text-* / --brand / --accent，随主题变）
    ↓
组件别名（--color-brand-600 → var(--brand)，--space-5 → var(--sp-5)）
```

**规则**：组件只允许引用"组件别名"或"语义 token"，禁止直接写 HEX；新增颜色必须先加调色板再语义化。

## 2. 字体与排版

| 层级 | 字族 | 字号 | 行高 | 字重 | 用法 |
| --- | --- | --- | --- | --- | --- |
| Display | 衬线 | clamp(2rem, 1.2rem+3.4vw, 3.6rem) | 1.2 | 700 | 轮播主标题 |
| H1 | 衬线 | clamp(1.7rem, 1.2rem+2.4vw, 2.9rem) | 1.25 | 700 | 内页横幅标题 |
| H2 | 衬线 | clamp(1.4rem, 1.1rem+1.2vw, 2rem) | 1.3 | 700 | 区块标题 |
| H3 | 衬线 | 1.15rem | 1.4 | 600 | 卡片标题 |
| Body | 无衬线 | 1rem (--fs-md) | 1.9-2.05 | 400 | 正文 |
| Small | 无衬线 | 0.8125rem (--fs-sm) | 1.75 | 400 | 描述、元信息 |
| Caption | 无衬线 | 0.75rem (--fs-xs) | 1.6 | 400 | 标签、时间 |

- 字族：`--font-serif: 'Songti SC', 'STSong', 'Source Han Serif SC', 'Noto Serif SC', SimSun, Georgia, serif`；`--font-sans: 'PingFang SC', 'HarmonyOS Sans SC', 'Microsoft YaHei', 'Noto Sans SC', system-ui, sans-serif`。
- 中文标题不加粗到 800（宋体过粗失真），最大 700。
- 正文每行控制在 26-40 个汉字（`max-width: 62ch`）。
- 英文 kicker 用 0.16-0.3em 字间距，全部大写。

## 4. 栅格与断点

| 断点 | 容器最大宽 | 栅格 | 说明 |
| --- | --- | --- | --- |
| ≥1280px | 1200 / 1400（wide） | 4 列 / 3 列 / 6 列 | 显示左侧边栏导航 |
| 1024-1279px | 1200 | 3 列 | 隐藏边栏导航 |
| 768-1023px | 100% - 2×24px | 2 列 | 详情页主栏与侧栏上下堆叠 |
| 480-767px | 100% - 2×20px | 1 列 | 抽屉导航、单列卡片 |
| <480px | 100% - 2×16px | 1 列 | 表格横向滚动、字号保持 ≥14px |

- 页面左右留白 `--gutter`：桌面 24px、移动 16px。
- 页眉高度 `--header-h`：72px（桌面）/ 64px（移动）。
- 所有栅格容器子项强制 `min-width: 0`，防止内容撑破。

## 5. 组件规范

### 5.1 按钮

| 类型 | 背景 | 文字 | 圆角 | 内边距 | 状态 |
| --- | --- | --- | --- | --- | --- |
| Primary | --brand | #fff | 999px | .65em 1.4em | hover 上移 2px |
| Ghost | transparent + 1px 描边 | --text | 999px | .6em 1.5em | hover 背景 --brand-soft |
| Link | 无 | --brand | — | — | hover 下划线 offset 4px |

### 5.2 卡片

- 结构：封面图（4/3 或 16/10）+ 内容区（标题/描述/元信息/标签）。
- 描边 1px --border-subtle，圆角 --r-lg，背景 --bg-elevated。
- hover：上移 4px + --sh-lg + 描边转 --color-brand-200。
- 焦点：outline 2px --color-focus，offset 3px。

### 5.3 标签（TagPill）

| tone | 背景 | 文字 | 用途 |
| --- | --- | --- | --- |
| brand | --brand-soft | --brand-700 | 主题标签 |
| gold | 金色 16% | --gold-600 | 稀有/等级 |
| cinnabar | 朱砂 14% | 朱砂 700 | 辣度、活动分类 |
| muted | --bg-muted | --text-secondary | 中性元信息 |
| ghost | 透明 + 1px currentColor | 继承 | 深底上的标签 |

### 5.4 输入框

- 高度 40px、圆角 999px（搜索）/ --r-sm（表单）、背景 --bg-muted。
- 占位符 --text-tertiary；聚焦描边 --brand-400 + 2px 光晕。
- 必须有关联 label（可用 .sr-only 隐藏）。

### 5.5 页眉 / 页脚 / 边栏

- 页眉：sticky，两层（辅助功能区 40px + 主导航 72px），背景 color-mix(--bg-page 90%, transparent) + blur(14px)，底边 1px --border-subtle。
- 页脚：4 列（1.6fr / 1fr / 1fr / 1fr），顶部渐变，底部版权行。
- 边栏：固定左侧，胶囊容器，40px 圆钮，hover 显示文字气泡，≥1280px 显示。

## 6. 无障碍（A11y）

| 要求 | 落地 |
| --- | --- |
| 对比度 ≥ 4.5:1 | 正文墨色/宣纸、按钮白/竹青均达标；提供高对比模式 |
| 图片替代文本 | 所有 img 有描述性 alt；纯装饰图 aria-hidden |
| 表单标签 | 搜索框、问答输入均有关联 label |
| 键盘可达 | 全部交互元素可 Tab 聚焦，焦点环 2px + offset 3px |
| 语义标签 | header/nav/main/footer/section/article/ol/table + caption |
| 跳转链接 | 页首 skip-link 直达 #main |
| 动效偏好 | prefers-reduced-motion 关闭动画 |
| 屏幕阅读器 | role/aria-live 用于搜索结果计数与问答消息流 |

## 7. 图标与图像

- 图标使用 emoji（零依赖、跨平台彩色）：导航 8 个、服务 12 个、天气 8 个。
- 图像统一 SVG，比例 4:3（卡片）与 16:9（横幅），`object-fit: cover`。
- 不使用位图，避免 2× 图与压缩失真；SVG 经 Vite 生成 hash 指纹并长期缓存。

## 8. 命名规范

- CSS 变量：`--category-name-step`（如 --color-brand-600）。
- 组件：PascalCase，单文件同名（ScenicCard.vue）。
- BEM 风格类名：`.scenic-card`、`.scenic-card__body`（本项目采用 scoped CSS + 简短语义类，如 .body/.meta）。
- 组合式函数：use 前缀 + 动词（useScrollReveal）。
- 数据文件：领域复数（scenic.ts 导出 scenicSpots）。
