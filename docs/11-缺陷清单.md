## 遗留风险（非缺陷）

1. Firefox / Safari 未做自动化回归（环境限制），已人工核对这些浏览器对新 CSS 特性的支持范围。
2. 天气数据依赖公网，离线降级为示例数据，已在 UI 标注。
3. Lighthouse 的 best-practices 在 http 本地环境固定失分（is-on-https），部署 HTTPS 后消除。
